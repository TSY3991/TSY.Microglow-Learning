- [微光入口網站](https://tsy3991.github.io/TSY.Microglow-Website/)

## 維護

預設分支 main，GitHub Pages 從 main 根目錄發布。直接編輯 HTML、CSS 與 JavaScript，不需要建置。

- index.html：課程大廳與站群導覽。
- courses/ai-toolkit/：工具說明、官方來源、搜尋分類與引導文字複製。
- shared/base.css：共用微光暖白青綠風格。
- assets/：沿用正式品牌素材，不重繪 LOGO。

工具只連向原作者／供應商，不代管安裝檔，不自動安裝。更新 CSS／JS／圖片時同步升引用處的 ?v=。發布前檢查手機與桌機、搜尋、篩選、複製、返回連結與無 JavaScript 的可讀性。

主站舊課程網址保留轉址；新增教材應放在本 repo。
